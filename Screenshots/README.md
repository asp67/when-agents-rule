# README media

Captured from build 819 on 2026-09-09 with Cinematic graphics in the local
browser. All imagery comes from the game renderer; no generated artwork is used.

- `ArenaPoster.png`, `Winter.png`, `Desert.png`, `Night.png`: Iron Age
  civilization showcases. Captions identify the civilization, terrain and time.
- `Arena.gif`: 64 frames, 960 × 600, looping day/night preview. The twelve-minute
  cosmetic lighting cycle is accelerated to about nine seconds.
- `Formations.gif` and `Formations.png`: staged patrol with ten warriors, six
  archers and two priests, using the real standing-order and movement code.
  Forty frames at 720 x 450 show 24 seconds of simulation in eight seconds of playback.
- `AnalyzeTranscript.png`: the existing Episode 6 sample opened in the current
  analyzer. Its header correctly shows the original recording's build/version.
- `ModelLibrary.png`: current connection controls in a clean browser profile.
  No private endpoints, credentials or model-library exports are included.

The showcase HUD is reduced for the scenery captures. Demonstration labels are
capture-only overlays; they do not change the shipped game UI. Staged scenes
are not presented as autonomous model matches.
